## The Survey

The brief's **Verified state** is cited, never re-measured — whichever path below runs. The clause is the survey's own, not the fan-out's: a small-area survey that searches directly inherits it unchanged. It covers **stamped** claims only: an `inferred:` line the direction rests on — wherever it sits in the brief, inside that section included — is the re-verify register (the sweep skill's Claims section), and probing it is scout's, before define's interview builds on it; where the probe is a script, it is kept beside the map as a committed behavioral probe.

**Partition the work, not only the questions.** A search vector goes to exactly one lens, and a corpus several lenses share gets one **measuring lens** — the others cite its numbers rather than deriving their own. Size each lens net of what the host session must read itself: a lens that re-reads what you are reading anyway buys nothing. Recall-first is a sweep's discipline (the sweep skill), where redundancy buys coverage; in fan-out design it only multiplies tool work.

Agents return compact fact sheets — paths with one-line roles, terms with where they're defined, claims quoted with file references — and any unprobed characterization (what a module is for, why a pattern holds) marked `inferred:`, never asserted as fact (register: the sweep skill's Claims section). They gather facts only: no design proposals, no coding-standards reading. You stay single-context and synthesize; if the sheets expose an area nobody covered, run one targeted follow-up — the map is a survey, not an audit. A sheet is session-ephemeral and is never cited downstream: the map is the compaction boundary, and anything a later phase needs is in it. A sheet that would exceed the agent-result cap is written to the topic folder and a pointer returned instead, so nothing arrives truncated from the head.

## The Survey Map (`survey.md`)

In a **prose corpus** — a suite or meta topic, where what the survey maps is written pages rather than code — the **section is the unit**: quoted text governs, and a `:line` ref beside it is an authoring-time lead, never the anchor. That is the altitude rule's form here, not an exemption from it.
