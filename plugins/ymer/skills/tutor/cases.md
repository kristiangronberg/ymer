# Tutor: cases

The cases of the tutor skill: the precision earned from runs and probes
that went wrong once, and why a rule is drawn where it is. The headings
are `SKILL.md`'s own; read a section's entries at the moment that
section runs.

## First, the stores

**Why a missing table can mean the wrong node.** A project's
development instance of the node, or any other server that exposes a
`notebook` tool, answers the same query as the user's own node does, and
holds no `tutor_*` table. Read as a missing setup, that would send the
user to `/ymer:setup` for a node no other session reads.

## Question Repertoire

**Why the table holds these types and not others.** Each kind of
material keeps what its own evidence showed. For hands-on material, the
gen-ui spike showed exposition-on-demand beating every quiz, so
pre-tests as interrogation and standing per-station probes stay out
there. For study-shaped material, the learning.md record corpus proved
the beat cycle, so self-explanation and elaborative interrogation are
admitted as its probe pool: a named refinement of the hands-on
exclusion, never a silent reversal of it. Prediction → observation is
pre-testing's hands-on form, and the study beat's predict-first step is
its study form. Interleaving lives in the retrieval opener's
cross-station phrasing, not as a standing type.

## Knowledge Docs

**The slug, probed.** The store's slug derivation was probed on
2026-08-30, both halves, against scratch docs since deleted: a
title-only update moved slug `zz-scratch-probe` →
`learning-zz-scratch-probe`, and a `create` titled `Learning ZZ Scratch
Probe` with no slug landed as `learning-zz-scratch-probe`. A body-only
update was never probed without the slug, so it is not assumed safe,
and the rule to state the slug covers it too.

**What the whole-body root costs.** A section write against it leaves
only the text sent. On an engagement doc that is the entire engagement
record gone in one call, which is why every section write resolves its
node from `docs get_structure` rather than naming the root.
